# 墨隐 Inkveil

一个原生、轻量的 Windows TXT 小说阅读器。窗口没有实体背景，只显示文字；鼠标进入窗口时文字显现，鼠标离开或切换到其他程序后整个窗口隐入桌面，隐藏时允许鼠标点击穿透。

## 特性

- **悬停显示**：鼠标进入即淡入，离开或切换到其他程序后完全透明，不遮挡桌面。
- **点击穿透**：窗口隐藏后不会拦截下方程序的鼠标操作。
- **透明背景**：背景和文字不透明度可分别调节，默认背景全透明、文字完全不透明。
- **系统字体**：可选择 Windows 中安装的全部字体。
- **轻量原生**：使用 .NET Framework 4.8 + WPF，无 Electron、无 NuGet 运行时。
- **TXT 阅读**：支持拖入文件、章节识别、章节跳转、字号调整，重启后自动打开上次小说并恢复章节与位置。
- **编码兼容**：自动识别 UTF-8、UTF-16、UTF-32、GB18030/GBK。
- **整窗滚动**：鼠标位于窗口任意位置均可使用滚轮阅读。
- **透明滚动指示**：只显示细窄进度滑块，不出现白色滚动条轨道。

## 使用

1. 双击 `dist\Inkveil.exe` 启动。
2. 将 TXT 小说拖入窗口，或按 `Ctrl+O` 选择文件。
3. 点击右上角 `···` 打开显示设置，可调整背景/文字不透明度、字体与窗口行为。
4. 鼠标移出窗口或切换到其他程序后自动隐身；切回墨隐并将鼠标移回窗口区域即可重新显示。

系统要求：Windows 10/11。程序使用系统自带的 .NET Framework 4.8，无需额外安装运行时。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+O` | 打开小说 |
| `Alt+←` / `Alt+→` | 上一章 / 下一章 |
| `Ctrl++` / `Ctrl+-` | 调整字号 |
| `Ctrl+滚轮` | 调整字号 |
| `滚轮` | 在窗口任意位置滚动正文 |
| `Ctrl+T` | 切换浅色文字 / 深色文字 |
| `Ctrl+P` | 切换窗口置顶 |
| `Ctrl+H` | 切换“离开或切换程序即隐藏” |
| `Esc` | 关闭显示设置面板 |

阅读设置保存在 `%APPDATA%\Inkveil\settings.json`。

## 构建

项目不依赖 NuGet，使用 Windows 自带的 .NET Framework 编译器构建：

```powershell
.\build.ps1 -Test
```

输出文件为 `dist\Inkveil.exe`。`-Test` 会同时编译并运行章节解析、编码识别与阅读设置持久化测试。

也可以使用 Visual Studio 或 MSBuild 打开 `src\Inkveil.csproj` 进行构建。
